 Curry Stream

A lightweight, secure video streaming platform built with HLS (HTTP Live Streaming), powered by FFmpeg for video encoding, Firebase Authentication for secure user login, and Video.js for seamless client-side playback.
Features

     User Authentication
    Secure login/signup flow using Firebase Auth

     Video Upload & Encoding
    Uploaded videos are encoded to HLS format using FFmpeg for adaptive streaming

     HLS Playback
    Stream videos smoothly via Video.js with .m3u8 playlists

    ⚙ Client-side Player
    Fully responsive and customizable video player powered by Video.js
